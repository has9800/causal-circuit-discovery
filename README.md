# causa-heads

Find attention heads in GPT-Neo that respond differently to **causal vs correlational** reasoning prompts using TransformerLens.

## Features

- Loads GPT-Neo via `HookedTransformer.from_pretrained` with configurable debug mode (`gpt-neo-125m`)
- Validates externally provided `data/pairs.json` prompt pairs
- Records per-head activations from `hook_z` and attention patterns from `hook_pattern`
- Computes differential activation, activation ratio, KL divergence, and paired t-tests
- Runs top-head zero ablation plus random-head baseline ablations
- Saves Plotly visualizations (global + per-type)

## Quickstart

```bash
pip install -r requirements.txt
python scripts/run.py --config config.yaml
```

## `pairs.json` format

Use externally provided pairs; prompts are never generated by code.

```json
[
  {
    "causal": "Smoking causes lung damage. Lung damage causes cancer. Does smoking cause cancer? Answer:",
    "correlational": "Smoking correlates with lung damage. Lung damage correlates with cancer. Does smoking correlate with cancer? Answer:",
    "causal_answer": "Yes",
    "correlational_answer": "No",
    "type": "transitivity"
  }
]
```

## Outputs

Saved to `output.dir` (default: `results/`):
- `heatmap_differential_activation.html`
- `heatmap_p_values.html`
- `ablation_comparison.html`
- per-type differential heatmaps when multiple types are present

## Notes

- Use `model.debug: true` to run `EleutherAI/gpt-neo-125m` for faster checks.
- Precision is fixed to float32.
- Interventions are done only through hooks (`run_with_hooks`), weights are unchanged.
